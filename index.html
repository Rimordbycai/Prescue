Catatan teknis & tindak lanjut

Prioritas mengikuti hasil yang benar-benar teramati.

1
Selidiki sumber penurunan tekanan

Selisih tekanan mengindikasikan kebocoran atau perubahan kondisi selama pencatatan; penyebab belum terbukti.

2
Periksa sambungan pneumatik

Mulai dari selang dan konektor manset, termasuk pengencang, dengan prosedur aman.

3
Ulangi uji L dengan SETTLE lebih lama

Usulan berikutnya: ubah SETTLE menjadi 120 detik, RECORD tetap 60 detik. Jangan menganggap ini hasil yang sudah diuji.

4
Lanjut ke E/F setelah L lolos

Mode tahan tekanan dan deflasi belum menjadi bukti keberhasilan pada rekaman ini.

SIAP DISAMBUNGKAN

Integrasi ESP32 Web Server

Dashboard mendukung pembacaan data ESP32 melalui Wi-Fi dan HTTP API.

Pengaturan sumber data

Atur koneksi ESP32 untuk mengaktifkan pemantauan langsung.

Gunakan URL ESP32 saat Wi-Fi terkoneksi, atau URL proxy untuk pengembangan.
